### 你好，我是 YYY-DXS 👋

高中生，用 AI 写小软件和 DIY 项目。习惯是：发现一个真实的小麻烦 → 用一个周末把它做成能用的工具。

**正在做的三件事**

- 🧩 **DeepSeek Harness 插件** —— 让 Agent 能查余额、读历史、驱动本机软件
- 🪟 **Windows 桌面小工具** —— 解压即用，不装运行环境，配置只留在本机
- 🔧 **DIY 项目** —— 齐柏林飞艇、外骨骼、台历、航模方向

### 技术栈

`Python` · `PowerShell` · `C#` · `Node.js` · 一点前端（原生 HTML/CSS/JS）
构建与发布全走 GitHub Actions；打包用 PyInstaller 和 csc，不引入重型框架。
